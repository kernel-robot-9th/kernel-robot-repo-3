# Pinky 주행 연결 대기

Pinky Pro 2대를 고객별로 배정하며, 한 대가 최대 3개씩 싣고 필요한 차수만큼 왕복한다. 관제 명령·모의 중계는 준비돼 있지만 이 폴더에는 아직 실제 주행 코드가 없다.

확인한 `pinky-omx-sim2real` 로컬 저장소는 계획 자료이며 실제 주행 구현이 아니므로 가져오지 않았다. 개인 Isaac Sim/Isaac Lab 프로젝트도 팀 실행 코드와 분리한다.

현장 주행 코드·맵·정차 좌표를 받은 뒤 이 폴더에 포함한다. 그때 실제 ROS 2 배포판, 토픽/서비스/액션 및 메시지 타입, 로봇별 namespace, 후진 정차·정렬 확인 방법을 확인해 관제 어댑터를 연결한다. 명령 수락과 도착·정렬 확인, 정지 완료를 별도 결과로 전달해야 한다. 미확인 인터페이스를 임의로 선언하지 않는다.
