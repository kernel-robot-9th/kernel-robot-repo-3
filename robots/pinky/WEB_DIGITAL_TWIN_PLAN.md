# Three.js 웹 디지털 트윈 계획

작성: **2026-10-29** · 상태: **설계 정리 완료 / 기능 구현 미착수**

## 요약 — 먼저 볼 내용

- **착수 순서:** OMX 재캘리·시험에서 발견한 수정 반영 → 진행 상황을 이 세션에 인계 → 변경 사항·Git 정리 → 디지털 트윈 구현.
- **목표:** 기존 관리자 화면에서 Pinky 2대와 OMX의 실제 상태를 3D로 표시하고, 작업 과정·오류·이력을 재생한다.
- **최초 결과물:** Pinky 위치·방향, 작업 상태, 계획 경로·실제 궤적, 현장 영상을 함께 보는 화면. 기록 수집도 이때 시작한다.
- **재사용:** Vue·FastAPI·게이트웨이·카메라 중계·주문 상태·주행 기록과 Gazebo의 로봇 모델·관절 변환 코드.
- **주요 추가 작업:** 실제 OMX 관절값 전송, 공통 상태 형식, 웹용 모델, 통합 기록·재생.
- **Gazebo:** 별도 물리 시뮬레이션·Sim-to-Real 검증 환경으로 유지한다. 웹 화면 실행에 Gazebo를 필수로 두지 않는다.

전체 작업 목록: [Pinky 관제 시연 체크리스트](CAMERA_NAV_DEMO_PLAN.md).
이 문서는 후속 작업 계획이다. 작성 완료가 구현·배포·실물 시험 완료를 뜻하지 않는다.

## 3. 권장 구조와 표현 기준

```text
Pinky Nav2 + 전체 카메라 ─┐
OMX 실행부의 실제 관절값 ─┼→ 기존 게이트웨이·관제 서버 → Vue + Three.js
주문·작업·오류 상태 ──────┘             └→ 움직임·이벤트 기록 → 재생

Gazebo: 별도 실행, 모델·배치·경로 설정 및 기록 형식 재사용
```

- 기존 2D 화면은 유지하고 별도 3D 메뉴를 추가한다. 최초 화면은 상태 관측 중심으로 구성한다.
- 상태에는 로봇/장비 ID, 관측 시각, 수신 시각, 데이터 출처·좌표계, 위치·방향 또는 관절값, 작업 ID를 포함한다.
- Pinky의 P1/P2·gateway ID와 OMX A/B/C·Gazebo 모델 이름 대응을 한 곳에서 관리한다.
- 좌표는 기존 map/layout 변환을 재사용하고 길이는 m, 각도는 rad로 통일한다. ROS와 3D 축 변환도 한 곳에서 처리한다.
- 상단 마커 높이 143mm와 바닥의 로봇 기준점을 구분한다. 기존 카메라 재캘리를 이번 작업의 선행 조건으로 추가하지 않는다.
- 가벼운 위치·관절 전용 조회를 우선 사용한다. 초기 수신 목표는 5~10Hz이며 실제 처리량을 확인한다. 화면은 수신값 사이를 보간해 렌더링한다.
- 주문 전체 상태를 고빈도로 조회하지 않는다. 푸시 전송 전환은 필요가 확인되면 검토한다.
- 카메라 관측과 Nav2 추정의 출처를 구분한다. 관측이 없으면 마지막 상태와 갱신 시각을 표시한다.
- 경로는 실제 배포된 로봇별 경로와 적용 버전을 사용한다. 일반 경로 미리보기를 현장 실측 경로로 표시하지 않는다.
- 바구니 모델은 실측 크기를 표시한다. 계산용 70% 영역은 선택적으로 겹쳐 표시한다.

### OMX 실제 동기화

- 현재 모터를 제어하는 프로세스에서 실제 관절값을 읽어 전송한다. 별도 시리얼 리더를 동시에 실행해 포트를 중복 점유하지 않는다.
- 기존 위치 읽기와 관절 변환 로직을 재사용하되 축·영점·모델 링크 대응을 확인한다.
- 주문 worker 실행과 직접 터미널 실행 모두 같은 관측 경로로 연결한다.
- 목표 관절값을 실제 측정값으로 표시하지 않는다. 실제 관측이 없는 구간은 마지막 관측 상태로 구분한다.
- C는 VLA 실행부가 준비되기 전까지 정적 모델과 작업 상태를 표시하고, 준비 후 관절 상태 출력을 연결한다.
- 상품 슬롯 상태는 작업 데이터에 연결하되 소프트웨어 완료와 실제 물체 적재·하역 확인을 구분한다.

### 모델과 화면

기존 로봇 메시를 glTF/GLB로 정리하되 OMX 관절 축·원점·링크 구조를 보존한다. 원본 자산의 라이선스·출처도 유지한다. Gazebo 과거 배치를 그대로 복제하지 않고 현재 현장 설정을 기준으로 배치한다.

- 중앙: 바닥·도로·작업대·Pinky 2대·OMX 3대.
- 로봇·구역 표시: 이동 목적지, 집기·적재·하역 단계, 오류.
- 경로 표시: 계획 경로와 실제 궤적.
- 옆 패널: 선택 로봇의 주문·슬롯 상태·최근 오류 및 실제 영상.
- 하단: 실시간/재생 구분, 타임라인, 일시정지, 배속, 이벤트 이동.

- [ ] 기록이 있는 경우 카메라 영상도 같은 시간에 맞춰 표시.
