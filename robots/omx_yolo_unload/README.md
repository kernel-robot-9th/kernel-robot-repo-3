# C 구역 OMX YOLO 하역 계획

갱신: **2026-10-30** · **코드·현장 명령 준비 / C 배포·캘리·실물 시험 미실시**

## 요약

- **최우선 목표:** Pinky 바구니의 상품을 C에서 꺼내 수령 바구니에 놓고, 관제 주문 완료·대기 복귀까지 연결해 전체 시연 영상을 확보한다.
- **방향:** 사용자 보고로 기존 하역 진행이 실패하여, A/B에서 사용한 YOLO 좌표 집기 방식을 재사용하는 방안으로 전환한다. C에서의 성공 여부는 아직 검증하지 않았다.
- **순서:** C 현장 확인 → 상품 1개 하역 → 3슬롯 하역 → P1/P2 연결 → 주문 1건·상품 6개 전체 시연·촬영.
- **관리 위치:** 이 폴더는 C YOLO 하역 전용 계획·인계·실행 연결을 관리한다. 공통 집기 코드는 `robots/omx_yolo`를 재사용하며 전체 복사본을 새로 만들지 않는다.
- **후속:** 시연·촬영을 확보한 뒤 [Three.js 트윈](../pinky/WEB_DIGITAL_TWIN_PLAN.md)과 [ACS](../pinky/ACS_NAVIGATION_PLAN.md)를 진행한다.

C Codex 인계: [C_CODEX_HANDOFF.md](C_CODEX_HANDOFF.md). 준비 브랜치: `codex/c-yolo-unload-20261030`.

현장 복붙 명령: [FIELD_COMMANDS.md](FIELD_COMMANDS.md). 코드 전달 패키지 생성: `python3 scripts/package_c_yolo.py`.

전체 목록: [관제 시연 체크리스트](../pinky/CAMERA_NAV_DEMO_PLAN.md).

## 최소 동작 흐름

```text
C 정밀주차 완료
→ 관제의 해당 로봇 적재 목록·슬롯 확인
→ 바구니 영역에서 해당 상품 YOLO 검출
→ C 전용 캘리로 집기 XY 계산 + 상품별 집기 높이 적용
→ 접근 → 집기 → 들어 올리기
→ 수령 바구니 접근 → 놓기 → 그리퍼 개방 → 복귀
→ 항목별 결과 보고 → 다음 상품
→ 하역 결과 인계 → 주문 완료·대기 복귀
```

위 흐름의 C YOLO 실행기를 준비했다. 기존 관제 `HANDOFF`를 사용하며 `unload_engine=yolo` 설정으로 선택한다. 현장 설정 연결·실물 시험은 남아 있다.

## 재사용할 것 / C에서 준비할 것

| 항목 | 재사용 | C 전용 준비 |
|---|---|---|
| 검출 | `robots/omx_yolo/tools/picking/pick_vision.py`, 기존 상품 모델 | 바구니 위에서 본 상품의 검출·가림·포장 방향 확인 |
| 좌표·집기 | `pick_core.py`, IK·모터·그리퍼 제어 | C 카메라→팔 XY 캘리, 바구니 안 상품의 높이·집기 위치 |
| 위치별 보정 | `omx_spatial_correction.py`의 계산 기능 | 기본 집기 결과에 필요할 때 C에서 직접 측정한 값 사용 |
| 자세 기록 | 기존 키보드 조작·자세 기록 도구 | 바구니 집기 접근·들어 올림·수령 바구니 접근/놓기·대기 자세 |
| 관제 연결 | `station_remote.py`, `pinky_station.py`, 기존 하역 작업·결과 보고 | C의 `ActArm` 분기에서 YOLO 하역 실행기를 선택하는 연결 |
| 영상·기록 | 카메라 중계·재연결·부분 완료 기록 | C 카메라 공유 방식, 상품별 결과·원인·사진/영상 |

A/B 캘리·자세·위치별 보정값은 C로 복사하지 않는다. A 전용 모터 14번 보정도 복사하지 않는다.
기존 C ACT/VLA 모델·데이터·설정은 보존하고, 이번 시연용 YOLO 하역과 구분한다.

## 1. C 현장 확인 — 다음 작업

- [ ] 실제 C 팔 종류·포트·모터 ID·카메라·실행 가상환경·기존 설정 확인.
- [ ] 현재 팀원 프로세스와 카메라 사용 상태 확인 후 작업 시점 조율.
- [ ] P1/P2 정밀주차 시 상품과 그리퍼 접근 영역이 카메라에 보이는지 확인.
- [ ] 사용할 상품을 바구니에 놓고 기존 모델의 위쪽 시점 검출 확인. A/B 성공을 C 검출 성공으로 간주하지 않는다.
- [ ] C 캘리 기준면과 상품 집기 높이 결정. 바닥·선반 캘리를 높이가 다른 바구니 상품에 그대로 적용하지 않는다.
- [ ] P1/P2와 수령 바구니 좌/우 대응을 기존 주문 규칙에서 확인.

검출은 되지만 집기가 어긋나는 경우 좌표·Z를 먼저 확인한다. 검출 자체가 안 되는 경우 해당 상품의 학습/촬영 조건 문제로 따로 기록한다.
